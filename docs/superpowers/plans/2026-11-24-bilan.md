# Bilan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un onglet « Bilan » (ordinateur et téléphone) qui dit en une phrase si la semaine ou le mois a été bon, détaille chaque mesure, montre les habitudes CO₂ heure par heure et donne 2–3 constats.

**Architecture:** Les bandes de zones passent dans `server/src/zones.ts`, partagé avec le web. Une fonction pure `buildReport` (`server/src/report.ts`) calcule tout à partir des moyennes par minute ; `server/src/reportText.ts` écrit les phrases. La route `GET /api/v1/devices/:id/report` lit la base et appelle `buildReport`. Le web calcule les bornes de période (`period.ts`) et affiche `ReportView`, utilisé par la page ordinateur et l'onglet mobile.

**Tech Stack:** Fastify 5, node:sqlite, zod, Vitest ; React 19, Vite.

**Spec:** `docs/superpowers/specs/2026-11-24-bilan-design.md`

## Global Constraints

- Aucune migration de base (`server/src/db.ts` inchangé). Ne pas toucher `../aqa-app-ntfy`.
- Seuils de zones : une seule définition, dans `server/src/zones.ts`. `server/src/types.ts` reste sans code à l'exécution.
- Textes en français, tutoiement ; espace insécable (` `) avant `%`, `h`, `ppm`, `µg/m³`, `°C`, `dB` dans tout texte généré.
- Style : pas de cartes arrondies à ombre, pas de dégradés, pas de badges-pilules, pas d'emoji ; la couleur n'est jamais le seul signal.
- Commits `feat(bilan): …` sur `feat-bilan`, pas de push ni de PR.
- `npm test`, `npm run typecheck`, `npm run build` passent à la fin de chaque tâche.

## Review Focus

- Carte hors ligne toute la période précédente → comparaison « Pas assez de mesures … pour comparer », jamais « Mieux que ». (Tâche 4)
- Semaine du changement d'heure (Europe/Paris, dimanche 25 oct. 2026, 3 h → 2 h) → heures locales justes, 169 h dans la semaine du 19 oct. (Tâches 2 et 6)
- Son non calibré, ou PM2.5 absent (capteur manquant) → pas de zones pour le son, verdict calculé sur le CO₂ seul, aucune exception. (Tâche 3)
- Période future ou antérieure à la carte → verdict « Pas de mesure … », `takeaways` vide, pas de division par zéro. (Tâches 3–4)
- Paramètres invalides (`to <= from`, plus de 32 jours, fuseau inconnu) → 400. (Tâche 5)

  ```ts
  export type ReportKind = "week" | "month" | "custom";
  export interface ZoneTime { word: string; tone: Tone; seconds: number }
  export interface MetricPeriod { measured_s: number; zones: ZoneTime[] | null; avg: number | null;
    min: { v: number; ts: number } | null; max: { v: number; ts: number } | null }
  export interface Comparison { trend: "better" | "worse" | "same" | null; text: string }
  export interface MetricReport { metric: Metric; current: MetricPeriod; previous: MetricPeriod; comparison: Comparison | null }
  export interface AirTime { measured_s: number; good_s: number; warn_s: number; bad_s: number }
  export interface HeatRow { weekday: number; date: string | null; cells: (number | null)[] }
  export interface DeviceReport {
    device_id: string; kind: ReportKind; tz: string; from: number; to: number; prev_from: number; now: number;
    in_progress: boolean; elapsed_s: number; measured_s: number; prev_elapsed_s: number; prev_measured_s: number;
    sound_calibrated: boolean;
    verdict: { tone: Tone | null; head: string; rest: string };
    air: { current: AirTime; previous: AirTime };
    metrics: MetricReport[];
    heatmap: { metric: "co2"; by: "day" | "weekday"; rows: HeatRow[] };
    alerts: { current: number; previous: number; by_kind: { kind: AlertKind; label: string; count: number }[] };
    takeaways: string[];
  }
  ```
- Produces, dans `report.ts` : `interface ReportInput { deviceId: string; kind: ReportKind; tz: string; from: number; to: number; prevFrom: number; now: number; cal: SoundCalibration | null; step: number; current: AggregateRow[]; previous: AggregateRow[]; alerts: { current: AlertKind[]; previous: AlertKind[] } }`, `function buildReport(input: ReportInput): DeviceReport`, `const REPORT_STEP = 60`.
