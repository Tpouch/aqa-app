# Onglet Alertes — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Détecter côté serveur les dépassements durables (CO₂, PM2.5, température, humidité, son, carte hors ligne), les tenir dans un journal avec un conseil, et les afficher dans un nouvel onglet Alertes où l'on règle seuil et durée de chaque règle proposée.

**Architecture:** Un module pur `server/src/alerts.ts` décide, pour une carte et une règle, s'il faut ouvrir, mettre à jour ou fermer une alerte ; `checkAlerts()` l'applique à toutes les cartes et tourne toutes les 30 s depuis `buildApp`. Deux tables (`alert_rules`, `alerts`) et quatre routes admin. Côté web, un onglet `#/alertes` en deux colonnes (règles | journal), un compteur rouge dans la colonne de gauche.

**Tech Stack:** Fastify 5, zod 4, `node:sqlite`, Vitest 5, React 19, Vite, TypeScript.

**Spec:** `docs/superpowers/specs/2026-11-20-alertes-design.md` (à lire en entier avant chaque tâche). Maquette de référence : `.superpowers/brainstorm/381780-1795212962/content/alertes-layout.html`, **option B**.

## Global Constraints

- UI et textes (conseils, libellés) en français ; copie fixée dans ce plan quand il la donne.
- Style de la refonte UI : une police mono, filets 1px, pas d'ombre ni de dégradé, coins ≤ 2px, la couleur ne porte que les zones et n'est jamais seule (toujours un mot ou une pastille + texte), glyphes en `aria-hidden`.
- `server/src/types.ts` reste sans code d'exécution (importé par le client).
- Vérification toutes les **30 s** ; fermeture après **2 min** de retour sous le seuil ; fenêtre « couverte » = mesure la plus récente < **60 s** et plus ancienne de la fenêtre à < **60 s** de son début.
- Règles par défaut (seuil, durée, active) : `co2_high` 1200 / 300 s / oui ; `pm25_high` 35 / 300 s / oui ; `temp_low` 19 / 1800 s / oui ; `temp_high` 24 / 1800 s / oui ; `hum_low` 40 / 1800 s / oui ; `hum_high` 60 / 1800 s / oui ; `snd_high` 70 / 120 s / **non** ; `offline` — / 300 s / oui.
- Durée réglable de 60 à 14 400 s (1 à 240 min).
- Pas d'attribution IA dans les commits.
- `npm test`, `npm run typecheck` (racine) et `npm run build -w web` passent à la fin de chaque tâche.

## Review Focus

1. **Redémarrage du serveur** : aucune carte ne doit passer « hors ligne » parce que le serveur était arrêté — testé Task 1 (`offline: compte depuis le démarrage du serveur`).
2. **Mesures renvoyées en retard après une coupure** (horodatées dans le passé) : n'ouvrent pas d'alerte — testé Task 1 (`n'ouvre pas sur des mesures anciennes`).
3. **Capteur absent** (valeurs `null` sur toute la fenêtre) : ni ouverture ni fermeture — testé Task 1 (`fenêtre vide`) et Task 2 (`ignore les null`).
4. **Seuil modifié pendant une alerte ouverte** : la fermeture compare au seuil copié dans l'alerte — testé Task 1 (`ferme contre le seuil de l'alerte`).
5. **Carte sans calibration du son** avec `snd_high` activée : rien ne s'ouvre, rien ne plante — testé Task 2 (`ignore snd_high sans calibration`).

  ```ts
  export interface Sample { ts: number; v: number }          // trié par ts croissant, sans null
  export interface OpenAlert { threshold: number; peak_value: number | null }
  export type Decision =
    | { action: "none" }
    | { action: "open"; started_at: number; start_value: number | null; peak_value: number | null }
    | { action: "update"; peak_value: number }
    | { action: "close"; end_value: number | null };
  export const CATALOG: Record<AlertKind, { label: string; unit: string; metric: Metric | null;
    direction: "high" | "low" | null; tone: "warn" | "bad"; defaults: AlertRuleValues; advice: string; min: number; max: number }>;
  export const CLOSE_AFTER_S = 120, COVERAGE_S = 60, CHECK_EVERY_S = 30;
  export function decideMetric(kind: AlertKind, rule: AlertRuleValues, open: OpenAlert | null, samples: Sample[], now: number): Decision;
  export function decideOffline(rule: AlertRuleValues, open: boolean, lastSeen: number | null, serverStart: number, now: number): Decision;
  ```

Catalogue (libellé · unité · ton · bornes de seuil `min`–`max`) :
`co2_high` « CO₂ élevé » · ppm · bad · 400–5000 ; `pm25_high` « Particules fines » · µg/m³ · bad · 1–500 ; `temp_low` « Trop froid » · °C · warn · −10–40 ; `temp_high` « Trop chaud » · °C · warn · −10–40 ; `hum_low` « Air trop sec » · % · warn · 0–100 ; `hum_high` « Air trop humide » · % · warn · 0–100 ; `snd_high` « Bruit fort » · dB · bad · 30–120 ; `offline` « Carte hors ligne » · « » · bad · —.

Conseils (copie exacte) :
- `co2_high` : « Ouvre une fenêtre en grand 5 à 10 minutes. Si plusieurs personnes sont dans la pièce, laisse aussi la porte ouverte. »
- `pm25_high` : « Cherche la source (cuisson, bougie, fumée) et aère. Si la pollution vient de dehors, garde plutôt les fenêtres fermées. »
- `temp_low` : « Monte le chauffage ou ferme les fenêtres. Si tu viens d'aérer, la pièce se réchauffera d'elle-même en quelques minutes. »
- `temp_high` : « Baisse le chauffage, ferme les volets côté soleil, et aère quand il fait plus frais dehors. »
- `hum_low` : « Aère moins longtemps, fais sécher du linge dans la pièce ou utilise un humidificateur. »
- `hum_high` : « Aère 10 minutes, surtout après une douche ou la cuisine, pour éviter la moisissure. »
- `snd_high` : « Le bruit est fort depuis un moment. Ferme la fenêtre côté rue ou éloigne la source. »
- `offline` : « Vérifie que la carte est branchée et que le Wi-Fi fonctionne. La page Carte montre son dernier contact. »

Règle de `decideMetric` (au-delà = `v > seuil` pour `high`, `v < seuil` pour `low`) :
  ```
  si open :
    récents = samples avec ts >= now - CLOSE_AFTER_S
    si récents non vide, plus ancien.ts <= now - CLOSE_AFTER_S + COVERAGE_S,
       et aucun récent au-delà de open.threshold → close(end_value = dernier.v)
    sinon pire = pire valeur au-delà parmi récents ; si pire que open.peak_value → update
    sinon none
  sinon :
    fenêtre = samples avec ts >= now - rule.duration_s
    si vide, ou dernier.ts < now - COVERAGE_S, ou premier.ts > now - rule.duration_s + COVERAGE_S → none
    si toutes au-delà de rule.threshold → open(started_at = premier.ts, start_value = premier.v, peak = pire)
  ```
  `decideOffline` : `since = max(lastSeen, serverStart)` ; ouvre si `!open && lastSeen !== null && now - since > rule.duration_s` (`started_at = lastSeen`) ; ferme si `open && lastSeen !== null && now - lastSeen <= CHECK_EVERY_S * 2`.
